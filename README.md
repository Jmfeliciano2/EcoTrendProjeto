# EcoTrend

Site de e-commerce sustentável com foco em roupas, beleza, casa e tecnologia consciente.

## Descrição

O EcoTrend é uma landing page institucional/produtos voltada para consumo consciente, com uma estética clean, tipografia editorial e blocos temáticos para categorias sustentáveis.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- GitHub CLI (`gh`)

## Como visualizar

1. Abra o arquivo `index.html` no navegador.
2. Ou sirva a pasta localmente em um servidor simples, se preferir.

## Estrutura do projeto

- `index.html` — estrutura da página
- `styles.css` — estilos e layout
- `*.png`, `*.jpg`, `*.webp` — imagens dos produtos e destaques

## Objetivo

Apresentar uma marca de consumo sustentável com foco em materiais ecológicos, produtos duráveis e uma experiência visual moderna.
